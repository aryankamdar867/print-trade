# Print Trade (प्रिंट ट्रेड रंगतरंग)

> **Official Website & Digital Experience for Print Trade, Pune**  
> Authorized Industrial Supplier of Offset Printing Inks, Bar Blankets, Damping Clothes & Press Chemicals.

---

## 🌟 Key Features

- **Interactive 3D Visiting Card**:
  - Photorealistic 3D dual-sided trade card built with CSS 3D perspective transforms.
  - Front face showcases the official Print Trade registered business graphic with dynamic holographic foil glare.
  - Back face features executive matte black & gold stamping with Satish Khose's credentials, direct contact lines, and a scannable WhatsApp QR code.
  - Interactive mouse/touch tilt with realistic momentum damping and 360° flip animation.
  - Built-in one-click `.vcf` vCard contact downloader for smartphones.

- **Interactive 3D Pantone Swatch Fan Deck**:
  - Physical 7-blade swatch deck with real-time spread angle slider ($15^\circ$ to $90^\circ$).
  - Hover blade elevation with certified Delta-E tolerance readings ($\Delta\text{E} < 0.40$).

- **Bar Blanket Workshop Configurator**:
  - Direct OEM presets for Heidelberg (SM 74, SM 102), Komori (Lithrone 28, 40), and Ryobi presses.
  - Real-time specification calculator generating pre-filled WhatsApp quotes.

- **Authoritative Brand Alliances**:
  - Showcases factory partnerships with **Böttcher Systems (Germany)**, **Siegwerk**, **Sakata INX (Japan)**, **Perfect Graphics Chemicals**, and **QC / DIC / Huber**.

- **Non-AI Typographic Hierarchy**:
  - Headlines: **IBM Plex Sans**
  - Body Copy: **Inter**
  - Heritage Script: **IBM Plex Sans Devanagari**
  - Technical Specs: **IBM Plex Mono**

## 🚀 Local Development

No build step or Node dependencies required. Simply serve with any HTTP server:

```bash
# Using Python
python -m http.server 8080

# Or using Node http-server
npx http-server -p 8080
```

Open `http://localhost:8080` in your web browser.
